Getting Matchbook

There is no public download yet. The Mac app targets macOS 15.4 or later on Apple silicon. Email hello@matchbook.gg to ask about access. Pricing and public release timing are not announced here.

Your first session

  1. Open Matchbook and link your Riot account using the onboarding flow.
  2. Open League. From Home, set one focus for the session.
  3. Play your games. With recording enabled and permissions granted, supported games record automatically and match data imports afterward.
  4. Open Review, revisit a moment, and write a takeaway. Carry something useful into your next session.

The app is still in development. Some setup depends on the build you have; contact support if account verification fails instead of changing security settings to work around it.

Recording and flags

Allow Screen Recording

In System Settings → Privacy & Security → Screen Recording, allow Matchbook. The label may appear as Screen & System Audio Recording on newer macOS versions. Follow the system prompt if a restart is needed.

Matchbook records the League game window. During loading or tab-outs, capture can bridge to the display. Keep that in mind when switching to other content while recording.

Flag a moment with ⌘J

The default flag shortcut is Command + J. Enable Matchbook in System Settings → Privacy & Security → Accessibility for global hotkeys. You can change the shortcut in Matchbook's Recording settings. A modifier key is required so normal typing does not create flags.

A flag keeps the recording timestamp so you can return to it after the game. If the shortcut does not work, check Accessibility permission and the configured hotkey.

Review and clips

Open Review to find your games and recordings. Use quick review for the immediate takeaway, or open the full player to work through flags and timeline events. You can attach notes, record causes, and save a useful segment as a clip.

The clip library keeps saved moments together. Export a clip when you want a standalone video. Existing video files can also be imported for review; timeline alignment depends on the file and its match association.

Other devices

The core Mac practice workflow stores its data locally. Sign in for optional multi-device sync. Keep recordings and cloud clips distinct:

  • Full recordings on iPhone or iPad: pair with the Mac, keep both devices on the same Wi-Fi, and leave the Mac awake with Matchbook open.
  • Uploaded clips: Companion can stream cloud clips over an internet connection.
  • Apple Health: Companion can display supported health context when you grant access. You control those permissions.
  • Web: current work includes sessions, match history, stats, reflections, and notes. It is not a browser recorder.
  • Windows: currently an early prototype, with no native recording release available.

Sync and device access remain in development. If something is missing, keep the original data and contact support.
